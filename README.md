# USD BRep Parametric CAD

Browser-based JavaScript CAD with live parameter controls, tessellated 3D previews and exact USD BRep export using SMLib WASM.

[Launch app](https://tad-repos.github.io/261125_usdbrep-parametric-cad/)

Develop locally with Node.js 22.18+: `npm install`, then `npm run dev`. Build with `npm run build`.
